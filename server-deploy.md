# Розгортання n8n на сервері (з HTTPS — для робочого бота)

Це фінальний крок за ТЗ. На сервері з доменом Telegram-webhook працює автоматично, тож кнопка «Опублікувати», voice та ручний ввід запрацюють повноцінно (локально їх блокує відсутність HTTPS).

Файли для сервера лежать у папці `server/`: `docker-compose.yml`, `Caddyfile`, `.env.example`.

---

## Що знадобиться (і скільки коштує)

- **VPS** — рекомендую **Hetzner Cloud CX22** (2 vCPU, 4 ГБ RAM) ≈ **€3.79/міс**. Дешева й надійна. Альтернатива — Contabo VPS (дешевше, але повільніший саппорт).
- **Домен** — потрібен для HTTPS. Варіанти:
  - Дешевий: `.xyz` від ~$1/рік (Namecheap, Spaceship).
  - Безкоштовний: субдомен на **DuckDNS** (duckdns.org) — для нього теж видається валідний HTTPS-сертифікат.
- **Ключі** (ті самі, що локально): Telegram bot token, Groq API key. Tavily вже вшито.

---

## Крок 1. Орендувати VPS

1. Зареєструйся на **hetzner.com/cloud** → Create Server.
2. Локація: Nuremberg/Helsinki (ближче до України).
3. Образ: **Ubuntu 24.04**.
4. Тип: **CX22**.
5. Створи сервер. Запиши його **публічний IP** (напр. `203.0.113.10`).

## Крок 2. Домен → IP

Варіант А (свій домен): у панелі реєстратора додай **A-запис**:
`n8n.твійдомен.com → 203.0.113.10`

Варіант Б (безкоштовно, DuckDNS):
1. duckdns.org → увійди → створи субдомен, напр. `ainewsbot-n8n`.
2. У полі IP встав IP сервера → твій домен буде `ainewsbot-n8n.duckdns.org`.

## Крок 3. Підключитись до сервера і встановити Docker

Підключення (у PowerShell на твоєму ПК):
```powershell
ssh root@203.0.113.10
```
На сервері постав Docker однією командою:
```bash
curl -fsSL https://get.docker.com | sh
```

## Крок 4. Завантажити файли на сервер

На сервері створи папку і файли:
```bash
mkdir -p ~/n8n && cd ~/n8n
```
Скопіюй на сервер вміст `server/docker-compose.yml` і `server/Caddyfile` (через `nano docker-compose.yml`, встав, Ctrl+O, Enter, Ctrl+X; так само Caddyfile).

Створи `.env` зі своїм доменом:
```bash
echo "DOMAIN=n8n.твійдомен.com" > .env
```
(або `ainewsbot-n8n.duckdns.org`)

## Крок 5. Запустити

```bash
docker compose up -d
```
Caddy сам отримає HTTPS-сертифікат (1-2 хв). Перевір: відкрий у браузері `https://твійдомен` — має відкритись n8n із замочком HTTPS.

## Крок 6. Налаштувати n8n на сервері

1. Створи акаунт (email + пароль) — це новий інстанс.
2. **Credentials → Create:**
   - **Telegram API** — встав bot token.
   - **OpenAI** (для Groq): Base URL `https://api.groq.com/openai/v1`, API Key — ключ Groq.
3. **Імпортуй 4 workflow** з папки проєкту (`AI News Bot — *.json`): для кожного — Create Workflow → ⋮ → Import from File → по одному файлу.
4. У кожному workflow перевір, що ноди підхопили твої credentials (де порожньо — обери Telegram account / OpenAI account). Модель скрізь уже `openai/gpt-oss-120b`.

## Крок 7. Активувати

Увімкни (Active) всі 4 workflow. Цього разу **бот-хаб активується успішно** — бо webhook тепер HTTPS (`https://твійдомен/...`). Telegram прийме його.

## Крок 8. Перевірка

- Дочекайся автопосту (або тимчасово вимкни «Дедуплікація», запусти раз) — пост прийде в Telegram на модерацію.
- Натисни **✅ Опублікувати** — тепер кнопка працює: пост публікується в канал @your_channel.
- Перевір, що бот доданий **адміністратором** у канал (інакше публікація не пройде).

---

## Важливо
- **Безпека:** постав фаєрвол (Hetzner Cloud Firewall) — відкрий лише порти 22, 80, 443.
- **Резервні копії:** том `n8n_data` містить усі workflow і ключі. Hetzner має автобекапи (+20%).
- **Оновлення n8n:** `docker compose pull && docker compose up -d`.
- Локальний ключ Tavily вшито в ноду «Пошук Tavily» — на сервері він уже всередині імпортованого workflow.
