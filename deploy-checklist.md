# Чеклист для деплою «AI Love You» на сервер (Hetzner)

Зібрати це від власника AI News Bot перед запуском. Коли все є — настройку роблю я через браузер.

## Обовʼязкове

- [ ] **Hetzner Cloud** — акаунт з привʼязаною картою (сервер не створюється без білінгу). Оплату/2FA робить власник.
- [ ] **Telegram bot token** — токен того самого бота (від @BotFather).
- [ ] **Groq API key** — для генерації постів.
- [ ] **Домен** — один з варіантів:
  - [ ] свій домен + доступ до DNS реєстратора, або
  - [ ] безкоштовний субдомен DuckDNS (робимо разом).
- [ ] **Бот доданий адміністратором** у канал @your_channel з правом публікувати пости.

## Уточнити

- [ ] **Telegram ID** дозволених користувачів бота (зараз: `YOUR_TELEGRAM_ID`; додати ще?).
- [ ] Підтвердити юзернейм каналу (у гайді — `@your_channel`).

## Для браузерної частини (від виконавця)

- [ ] Підключене розширення **Claude in Chrome**.
- [ ] Відкрита залогінена сесія **Hetzner Cloud**.

## Що робитиму я (через браузер)

1. Створю сервер CX22 (Ubuntu 24.04) з cloud-init — Docker + n8n піднімуться автоматично, без SSH.
2. Налаштую DNS (A-запис домену на IP сервера).
3. У веб-панелі n8n: створю 2 credentials (Telegram, Groq), імпортую 4 воркфлоу, активую.
4. Перевіримо: тестовий пост → кнопка «Опублікувати» → публікація в канал.

## Ключі, які вже вшиті (нічого не треба)

- Tavily API key — уже всередині воркфлоу автопостингу.
